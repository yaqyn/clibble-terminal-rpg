# Clibble cover direction

The cover makes the command line the entrance to a small adventure. The name is
the first thing a reader sees; the cursor becomes a trail through character art.
This is conceptual title artwork, not an exact screenshot of the RPG renderer.
The app discovers locations, meets original wildlings, and stores their records through
commands. It does not have a navigable map, movement controls, or battles.

## Final edit prompt

Edit the previous cover while preserving the large exact name “Clibble”, tagline
“A little wild in your terminal.”, wide 2:1 layout, dark pine terminal canvas,
character-grid trees, cursor-path, restrained ivory and fern palette.
Replace the lower-left transcript with these exact lines:

```text
clibble > explore mosslight-woods
clibble > catch mosskin
mosskin was caught!
clibble > _
```

Replace the birdlike creatures with two original Mosskin: tiny round woodland
sprites with moss hoods, pale curious eyes, root feet, and a leaf umbrella.
Use chunky terminal-cell shapes and punctuation. Keep the illustration secondary
to the name. Add sparse rain slashes. No balls, existing game characters, 3D,
neon, glossy scenery, fake window chrome, combat, or movement-control promises.
