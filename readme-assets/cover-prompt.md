# Clibble cover direction

The cover makes the command line the entrance to a small adventure. The name is
the first thing a reader sees; the cursor becomes a trail through character art.
This is conceptual title artwork, not a screenshot of an ASCII world renderer.
The app discovers locations, catches Pokemon, and stores their records through
commands. It does not have a navigable map, movement controls, or battles.

## Final generation prompt

Use case: ads-marketing
Asset type: landscape README cover for Clibble, a playful terminal-first Pokemon exploration and catching game.
Create an intimate indie-game title screen INSIDE a terminal. The wilderness is made from monospace characters: punctuation, slashes, brackets, dots and chunky character-cell silhouettes. Flat front-facing full-bleed dark pine #142a25 canvas, generous breathing room, warm ivory #eef3d9 lettering, fern #a7c78b grass, muted sage #617e68 distant glyphs, tiny honey #e7be73 accent.
Left half: large beautifully crafted chunky monospace wordmark "Clibble", spelled C l i b b l e. It must be friendly, readable, with a subtle character-cell rhythm, not a corporate font. Beneath it exact tagline "A little wild in your terminal." Lower left short transcript with these exact lines:
"clibble > explore kanto-route-1-area"
"clibble > catch pidgey"
"pidgey was caught!"
"clibble > _"
Right half: a tiny wilderness in character art, winding dotted trail and sparse tall grass made of /\ characters, a few ASCII pine trees in the distance, and two small charming birdlike silhouettes assembled from terminal-cell shapes hiding in the grass. One nearest bird has a tiny warm amber capture spark. Let the trail begin at the final command cursor and wander into the clearing, so the command line feels like the doorway into a living little world. The scene dissolves into punctuation near the transcript. All art should seem possible in a terminal, with consistent character-grid spacing. Illustration is secondary to the name.
Mood: friendly, playful, curious, quietly magical, a small adventure waiting after Enter. Restrained craft, crisp flat edges and calm composition. About 2:1 aspect ratio.
Avoid: 3D, glossy dioramas, floating islands, laptops, monitors, ornamental window frames, browser chrome, window traffic-light dots, dashboards, neon green, cyberpunk, glows, gradients, excessive micro-detail, watermarks, badges, combat, movement controls, or fake features. No rendered creature illustrations. This is conceptual title artwork, not a screenshot. Preserve exact text and make it legible at README width.

## Production

Created with the built-in image generation tool. The selected image is converted
to lossless WebP with ImageMagick, then stripped and credited with ExifTool.
