# Dexrove visual assets

The name combines “dex” with “rove.” The identity is an independent Pokemon field
guide: an open-route D mark, cobalt highlights, cool mist surfaces, and ink text.
Palette values live in `internal/brand/identity.json`; vector marks and CSS tokens
are generated by `scripts/brand_assets.py`. Canonical heading-icon shapes remain
consistent with the workspace; their palette follows Dexrove.

`cover.webp` is the generated Dexrove cover, with the name and “Explore. Catch.
Keep.” visible. It was converted with ImageMagick using lossless WebP, stripped
with ExifTool, and given only these descriptive metadata fields:

- XMP-dc:Creator: Abdulrahman M. Yaqyn
- XMP-dc:Rights: Copyright Abdulrahman M. Yaqyn

The conversion preserves 1774 × 887 pixels and passed a zero-difference decoded
pixel comparison. No old EXIF/IPTC/XMP, location, software, device, or generation
metadata remains. SVG marks/icons stay vector. The bundled Manrope font retains
its separate OFL license and attribution.
