# Pokedex artwork

The SVG cover uses a handheld field-guide motif and a real command flow.
Charcoal `#16181d` is the background, off-white `#f3f0ec` carries text,
and coral `#ff6b73` is the primary accent. Heading icons preserve the workspace's
canonical geometry with 1.6-unit rounded strokes and a dark backing.
All artwork in this directory is vector; no Pokemon sprites are redistributed.
