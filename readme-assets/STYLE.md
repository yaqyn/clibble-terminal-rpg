# Clibble visual assets

Clibble (pronounced “clib-ul”) tucks CLI into a playful companion-like name.
The identity treats the terminal prompt as the beginning of a little adventure.
The vector mark is a chevron and block cursor; the cover's cursor becomes a trail
through character-art grass. The cover is conceptual title artwork, not a literal
screenshot or a promise of a navigable ASCII map.

Runtime palette values live in `internal/brand/identity.json`. Vector marks and
CSS tokens are generated by `scripts/brand_assets.py`. Canonical heading-icon
shapes retain their geometry and follow the new fern/pine palette. All SVGs remain
vector. Manrope retains its separate OFL license and attribution.

The cover uses pine #142a25, ivory #eef3d9, fern #a7c78b, sage #617e68,
and a small honey #e7be73 accent. The exact final prompt and creative constraints
are in [cover-prompt.md](cover-prompt.md).

`cover.webp` was generated with the built-in image generation tool, converted with
ImageMagick using lossless WebP, stripped with ExifTool, and given only:

- XMP-dc:Creator: Abdulrahman M. Yaqyn
- XMP-dc:Rights: Copyright Abdulrahman M. Yaqyn

The conversion preserves 1774 × 887 pixels and passed a zero-difference decoded
pixel comparison. No old EXIF/IPTC/XMP, location, software, device, or generation
metadata remains.
